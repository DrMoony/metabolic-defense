## 베타에 추가된 것
- **신규 몬스터**: 꽁초 니코틴(불씨·연기), 초록 소주병(간 피해 2.4배)
- **보스 3종 로테이션**: 킹 버거(왕관) / 암세포(쓰러지면 조각 4개로 분열) / 죽상경화 플라크(간 성벽을 뚫고 코어로 돌진)
- **무기 10단 트리**: 새총 → 석궁 → 화승총 → 권총 → 샷건 → 기관단총 → 소총 → **기관총(3점사)** → **바주카(광역 폭발)** → 레이저
- 무기 뷰모델 전면 강화(세레이션·스코프 렌즈·방열핀·탄띠·양각대·후폭풍 나팔 등)
- 등장 이펙트(지상 링 / 비행 스파클, 보스는 크게)
- **완전 이중 언어**: 시작화면·HUD·모든 안내 메시지·퀴즈·결과 리포트까지 한국어/English 전환
- **무기 파이프라인 완주**: 퀴즈 승급(+1) + 점수 18,000점마다 자동 승급 → 한 판에 레이저까지 도달 가능
- **세 게이지에 실제 역할 부여**
  - `CORE · 생명` — 0이 되면 게임 오버 (적이 성벽을 넘거나 비행 몹이 도달할 때 깎임)
  - `대사 건강(M)` — 아군 컨디션. 70↑이면 간 정화 파동 25% 빨라지고 췌장 회복 1.5배, 30↓이면 파동이 느려지고 **적이 10% 빨라짐**. 혈당이 안정되면 서서히 회복
  - `혈당` — 70을 넘으면 **간에 지방이 쌓이고**(섬유화 진행) 췌장이 급격히 지침. HUD에 경고 표시
- **재장전 & 무기 교체 (NORMAL·HARD 전용)**: 무기마다 탄창/재장전 시간, 탄창이 비면 자동 재장전, **재장전 중 우클릭으로 보유 무기 교체**. EASY는 탄약 무제한
