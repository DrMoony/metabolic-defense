## 베타에 추가된 것
- **신규 몬스터**: 꽁초 니코틴(불씨·연기), 초록 소주병(간 피해 2.4배)
- **보스 3종 로테이션**: 킹 버거(왕관) / 암세포(쓰러지면 조각 4개로 분열) / 죽상경화 플라크(간 성벽을 뚫고 코어로 돌진)
- **무기 10단 트리**: 새총 → 석궁 → 화승총 → 권총 → 샷건 → 기관단총 → 소총 → **기관총(3점사)** → **바주카(광역 폭발)** → 레이저
- 무기 뷰모델 전면 강화(세레이션·스코프 렌즈·방열핀·탄띠·양각대·후폭풍 나팔 등)
- 등장 이펙트(지상 링 / 비행 스파클, 보스는 크게)
- **완전 이중 언어**: 시작화면·HUD·모든 안내 메시지·퀴즈·결과 리포트까지 한국어/English 전환
- **무기 파이프라인 완주**: 퀴즈 승급(+1) + 점수 18,000점마다 자동 승급 → 한 판에 레이저까지 도달 가능
- **HUD 지표를 셋으로 단순화** (우측 상단, 182×50px)
  - ❤️ `생명` — 0이면 게임 오버
  - 🎯 `명중률` — 70%↑이면 대사가 좋아지고, 40%↓이면 나빠짐 (몸이 상한다)
  - 🧠 `퀴즈` — 정답마다 생명 회복(+8) · 간 수리 · 무기 승급
  - 대사·혈당은 내부 수치로만 돌고, 나빠질 때만 경고 배지로 표시
    (`🩸 고혈당 · 간에 지방 축적`, `⚡ 대사 저하 · 적이 빨라짐`, `⚡ 대사 양호 · 장기 지원 강화`)
- **자동 재장전 & 무기 교체 (NORMAL·HARD 전용)**: 탄창이 비면 **약 1초** 자동 재장전. **조준선에 원형 게이지와 남은 시간**이 표시되고(교체 시에도 조준선에 무기명 표시), 재장전 중에는 조준선 십자만 흐려져요. **우클릭으로 다른 무기 교체**. EASY는 탄약 무제한
  - 재장전 속도 = 🎯**명중률**(0% 약 1.2초 / 100% 약 0.6초) × 🟤**간 상태**(건강 1.0 → 섬유화 1.5배)
  - 간이 굳으면 **인슐린 발사 간격도 늘어나요** (건강 대비 최대 1.6배, 10초당 10발 → 7발)
