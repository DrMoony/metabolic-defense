# ASTRA 6차 변경 기록

BRIEF-6의 전투 피드백과 장기 배치를 구현했어요. `beta/main.js`는 동작을 확인하는 참고 자료로만 읽었고, ASTRA의 시뮬레이션·스프라이트·고정 카메라 구조에 맞춰 새로 작성했어요.

## 전투 피드백

- 조준선 바깥에 무기별 색상의 원형 재장전 게이지 추가. 실제 재장전 총시간을 저장해 진행률을 표시하고, 완료 후 180ms 동안 빛난 뒤 숨김. 발사 킥은 70ms. 일시정지 중 진행 정지, 우클릭 교체 시 기존 재장전 취소, 빈 무기로 바꾸면 새 재장전 시작.
- 기본 체력 2 이상인 적은 첫 피격부터 머리 위 체력 표시. 잔량 띠의 왼쪽 끝 고정, 초록 `>50%` / 노랑 `>25%` / 빨강 `≤25%`. 일반 적 너비의 90%, 최소 2 CSS px 두께, 어두운 배경띠, 카메라를 향하는 방향 유지.
- 시럽·암세포·플라크는 피격 전부터 너비·두께가 각각 두 배인 머리 위 체력바 표시. 기존 `#boss`를 웨이브 표시 아래로 이동하고 이름·남은 체력·3색 잔량 표시.
- `waveBoss`로 웨이브 보스와 준보스 구분. 동시 등장 시 웨이브 보스 우선, 사망하면 살아 있는 준보스로 전환, 모두 사망하면 숨김. 준보스 처치가 웨이브 보스 클리어를 대신하지 않도록 기록도 분리.
- 무기 획득 시 이름·탄창·등급색을 표시하는 3초 배너 추가. 덫 등장 시 자물쇠를 쏘면 코어가 회복된다는 안내 추가. 자물쇠에 마지막 탄환을 쏜 경우에도 자동 재장전 시작.

## 간 가디언 배치와 파동

좌표는 원본 1672 × 941 플레이트 기준이며, 발 위치를 `groundPoint`로 변환해 배치했어요. 기존 장기 크기는 유지하고 웨이브·보스 HUD를 간 반대편으로 옮겼어요.

| 맵 | 이전 발 위치 | 변경 발 위치 | 그림에서 선택한 자리 | 합류점까지 거리 |
|---|---|---|---|---|
| 관상동맥 | (760, 309) | (805, 510) | 합류부 안쪽 가장자리 | 50.00px, 플레이트 높이의 5.31% |
| 대망 | (510, 209) | (917, 538) | S자 전경 굽이 안쪽 지방 둔덕 | 트렁크 없음 |
| 간굴모세혈관 | (829, 339) | (777, 671) | 세 수로가 모이는 우물 입구 옆 | 트렁크 없음 |
| 경동맥 | (897, 444) | (947, 402) | 합류부 오른쪽, 중앙 길 옆 | 53.54px, 플레이트 높이의 5.69% |
| 위 | (822, 371) | (699, 439) | 중앙 섬의 징검다리 쪽 가장자리 | 트렁크 없음 |
| 사구체 | (847, 456) | (844, 505) | 중앙 단상의 나선 길 쪽 가장자리 | 트렁크 없음 |
| 췌도 | (846, 399) | (444, 374) | 왼쪽 길과 중앙 섬을 잇는 다리 옆 | 트렁크 없음 |

합류점 거리로 반경을 정하는 원리를 유지하면서, 실제 경로의 양 갈래 마지막 6개 점과 트렁크 처음 3개 점을 모두 덮도록 보정했어요. 트렁크가 없는 맵은 각 길에서 간과 가장 가까운 점 주변의 최대 5개 점을 검사해요. 저장한 경로가 있으면 그 경로를 기준으로 계산해요.

`pulseRadius = max(합류점 거리 × 1.35 + 4, 검사점 최대 거리 × 1.06 + 1)`

| 맵 | 검사점 수 | 간에서 검사점까지 최대 거리 | pulseRadius |
|---|---:|---:|---:|
| 관상동맥 | 15 | 54.66 | 58.94 |
| 대망 | 5 | 12.95 | 14.73 |
| 간굴모세혈관 | 11 | 35.85 | 39.00 |
| 경동맥 | 15 | 402.31 | 427.45 |
| 위 | 5 | 18.06 | 20.14 |
| 사구체 | 5 | 12.76 | 14.52 |
| 췌도 | 10 | 51.77 | 55.88 |

위 거리는 Three.js 월드 단위예요. 경동맥은 분기당 점이 7개여서 마지막 6개에 지평선 가까운 원경 점도 포함되고, 역투영한 거리가 크게 나와요. 따라서 간을 옮겨도 전체 검사점 포함 조건 때문에 반경이 작아지지 않는 예외가 있어요. 이 범위를 임의로 잘라내거나 경로를 바꾸지는 않았으며, 실제 플레이에서 파동 범위와 난이도는 추가 확인이 필요해요.

파동 순간 간은 1.18배로 부풀었다가 0.35초 동안 원래 크기로 돌아오고, 링과 같은 연녹색으로 잠깐 빛나요. 링은 지면 `y=0.035`의 얇은 평면이며, 고정 카메라 원근에 따라 타원으로 투영돼요. 초반 확장을 완만하게 하고 최대 반경에 도달한 다음 사라지도록 조정했어요.

## 췌장 포탑

- 진행도 30%와 월드 z 좌표로 사거리를 제한하던 조건 제거. 맵 전체의 살아 있는 당류 적을 대상으로 진행도가 높은 적부터 요격.
- 밝은 청록 코어와 잔상 4개. 이동 후에도 화면 지름 최소 8 CSS px를 다시 계산. 원경 적까지 도달하기 전에 수명이 끝나지 않도록 출발 거리에 따른 속도 보정.
- 인슐린 코어·잔상·명중 링은 지형 뒤로 숨지 않는 지원 사격 효과로 표시. 명중 시 청록 스파크와 0.25초 링 추가.
- `lookAt`으로 목표 방향을 계산하고 스프라이트 몸통의 좌우 방향과 기울기에 반영. 발사 전 0.25초 동안 총구 충전, 발사 직후 0.15 월드 단위 반동과 복귀. 몸통과 총구에 같은 반동 적용.
- 기존 7개 포탑 자리는 유지. 불투명 픽셀 표본의 깊이 검사에서 7맵 모두 지형에 가리지 않는 것을 확인하고, 원경·전경 조준 때 총구가 화면 안에 있는지도 검사.
- 상태줄에 지원 사격 / 인슐린 약화 / 과로 / 인슐린 저항성 / 부전으로 인한 지원 중단 표시. 기존 기능 비율과 영구 부전 판정 유지.

## 검증

실행 명령:

```sh
node --experimental-vm-modules astra/tests/verify.mjs
```

`ASTRA.setManual(true)`와 `step`을 사용한 전체 검증을 통과했어요. 기존 7맵·3웨이브 실제 raycast 클리어 검사에 다음 검사를 추가했어요.

- 7맵별 준보스 상단 표시, 웨이브 보스 우선, 사망 후 전환·숨김.
- 체력 75%·50%·25%에서 색 전환, 왼쪽 끝 고정, 실제 투영 두께 2px 이상, 머리 위 바의 카메라 방향.
- 재장전 진행·완료·숨김, 일시정지, 우클릭 교체, 70ms 킥 복귀.
- 분기 합류점과 간의 거리 3~6%, 경로 검사점 거리 ≤ pulseRadius, 파동 크기·복귀·지면 방향.
- 7맵 장기의 불투명 픽셀 표본이 지형 가림막보다 앞에 있는지 검사. 현재 표본은 모든 맵에서 100% 노출.
- 1.18배 커진 간의 투영 사각형과 웨이브·보스 HUD 예상 영역의 분리.
- 원경·전경 조준 방향 변화와 총구 화면 내 위치, 진행도 1% 적 요격, 꼬리 4개·화면 지름 8px, 실제 명중·청록 링·스파크, 췌장 상태 문구.

결과는 `tests/verification.log`와 `tests/feedback-report.json`에 기록했어요. 기존 파티클 상한·공유 텍스처 정리·rAF 품질 조절 검증도 통과했고, 빌드 도구나 후처리 렌더 타깃은 추가하지 않았어요.

실제 WebGL 화면과 60fps는 이번 환경에서 확인하지 못했어요. `tests/browser.mjs`의 Chrome 실행은 SIGABRT로 종료됐고, 이어진 브라우저 도구의 localhost 접근은 자동 승인 검토에서 사용자 권한 거부 사유로 차단됐어요. 투영 계산은 실제 브라우저의 CSS 배치·GPU 성능 검증을 대신하지 않아요.

## 범위

수정·산출물은 모두 `astra/` 안에 두었고 커밋하지 않았어요. 런타임 import와 HTML의 캐시 쿼리는 모두 `?v=a9`로 올렸으며, 공유 문제은행·기본 drug 제외·Fisher-Yates·`astra_` 저장 키·`../vendor/three.module.js` 사용을 유지했어요.
