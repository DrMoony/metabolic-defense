# ASTRA — 메타볼릭 디펜스 재구축 브리프

## 너의 임무
`beta/` 의 게임과 **동일한 컨셉**을 가진 라이트건 아케이드 게임을, **처음부터 새로** 만든다.
기존 코드는 **참조만** 한다. 복사·붙여넣기 금지. 구조·렌더링·연출을 네 방식대로 다시 설계해라.
결과물은 이 `astra/` 디렉터리 안에만 만든다. `beta/`, 루트 `main.js`, `index.html` 은 **절대 수정하지 마라**.

## 최우선 목표: 3D 느낌을 훨씬 강하게
현재 beta는 2D 배경 이미지(`assets/bg.jpg`) 위에 3D 오브젝트를 얹은 하이브리드다.
astra는 **제대로 된 3D 씬**이어야 한다. 최소한 아래를 만족해라.
- 실제 3D 지형/장기 구조물로 공간을 구성 (배경 이미지에 의존하지 말 것)
- 원근이 살아 있는 깊이감: 안개(fog), 피사계심도 느낌, 레이어드 조명
- 그림자, 반사/발광(emissive), 파티클이 공간 안에서 동작
- 카메라가 살짝 흔들리거나 미세하게 움직여 입체감을 강화
- 몬스터가 원경→근경으로 다가올 때 스케일·조명 변화가 확실히 느껴질 것

## 게임 컨셉 (beta와 동일하게 유지)
대사건강(비만·MASLD/MASH·CKM) 학회 부스용 **고정 시점 디펜스 슈터**. 한 판 3~5분.
- 플레이어는 화면 안쪽으로 다가오는 **정크푸드 몬스터**를 쏴서 막는다
- **간(Liver Guardian)** 은 아군 거점이자 광역 정화 파동을 쏘는 허브
- **췌장(Pancreas)** 은 인슐린을 쏘는 자동 포탑. 혹사시키면 무력화→부전(T2D 서사)
- 몬스터가 방어선을 넘으면 **코어(심장·콩팥·뇌혈관)** 가 깎인다
- 중간중간 **퀴즈**가 나오고, 맞히면 무기가 승급하거나 장기가 회복된다
- 웨이브가 끝날 때마다 **보스**가 하나씩 등장한다
- 라이트건 = 절대좌표 마우스. 마우스만으로 완결되게 만들 것 (키보드 필수 금지)

## 반드시 공유해야 하는 것: 문제은행
퀴즈는 **새로 만들지 마라.** 기존 파일을 그대로 fetch 해서 쓴다.
- `../assets/quiz_aasld_ko.json` / `_en.json` — MASLD/MASH 46문
- `../assets/quiz_obesity_ko.json` / `_en.json` — Clinical Obesity 38문
- 스키마: `{ q, a[4], correct, diff: "easy"|"mid"|"hard", src?, drug?: true }`

### 절대 어겨선 안 되는 규칙
1. **`drug: true` 문항은 기본 출제 제외.** 제약 공정경쟁규약 대응이다.
   어드민에서만 켤 수 있게 하고, 기본값은 반드시 숨김이다.
2. 두 세트를 비율로 섞을 수 있어야 한다 (기본 MASLD 70 : Obesity 30).
3. 셔플은 **Fisher-Yates**. `sort(() => Math.random()-0.5)` 는 편향이 심해 금지.
4. 최근 출제 문항을 localStorage에 남겨 연속 플레이 시 중복을 피한다.
5. localStorage 키는 전부 **`astra_` 프리픽스**로 분리한다 (beta는 `xgb_`, jump는 `mj_`).

## 기술 제약
- **빌드 도구 금지.** 정적 파일만. `python3 -m http.server 8765` 로 바로 열려야 한다.
- Three.js는 `../vendor/three.module.js` (r170) 를 import 해서 쓴다. npm 설치 금지.
- 진입점은 `astra/index.html` + `astra/main.js`. 캐시버스터 `main.js?v=aN` 를 붙이고 수정할 때마다 올린다.
- 16:9 레터박스 고정 스테이지 (부스 TV 기준). 창 비율이 달라도 16:9 유지.
- 한국어/영어 이중 언어. 시작 화면에서 언어·난이도 선택.
- 디버그 핸들을 `window.ASTRA` 로 노출한다 (step, 상태, 스폰 등). 헤드리스 검증에 쓴다.

## 참조할 파일 (읽기만)
- `beta/main.js` — 현재 게임 로직 전체 (약 3000줄). 밸런스·연출 수치의 근거
- `beta/index.html` — HUD·오버레이 구조
- `HANDOFF.md` — 배치 확정값, 개발 함정, 웨이브 보스 설계
- `tools/prompts.py` — 캐릭터 아트 방향 (스프라이트 교체 작업 중)
- `jump/main.js` — 자매 게임(플랫포머) 참고용
