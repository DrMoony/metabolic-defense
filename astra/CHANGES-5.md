# ASTRA 5차 변경 요약

생성 PNG로 몬스터 13종·보스 3종과 장기·소품·아이템·무기를 교체하고 맵별 전경 크기를 맞췄어요. 수정 범위는 `astra/`이며 공유 에셋은 읽기만 했고 커밋하지 않았어요.

- `sprites.js`: 걷기 9종은 발밑, 비행 4종은 중심을 기준으로 정렬해요. 2프레임을 초당 5~9회 교체하며 단일 프레임 보스에는 더 큰 스쿼시를 적용해요. 피격 틴트·경로 방향 넉백·사망 회전과 시럽 밸브 약점을 지원해요.
- 모든 월드 이미지에 `alphaTest: 0.12`, `transparent: false`, `depthWrite: true`를 적용해 플레이트 오클루더와 같은 깊이 검사에 참여하도록 했어요. 사격은 원본 PNG 알파를 읽어 투명한 부분을 통과해요.
- `plate.js`, `maps/plates.js`: 화면상 경로 길이로 진행률을 계산한 뒤 바닥으로 역투영해요. 지평선 근처의 긴 월드 거리에 이동 시간이 몰리지 않으며 맵별 전경 기준점에서 일반 적 높이를 15%로 맞춰요.
- `world.js`: `assets/liver.png`, `assets/pancreas.png`를 원본 비율로 배치하고 췌장의 좌우 방향과 발사점을 맞췄어요. 12종 무기는 카메라 자식 평면이며 반동과 이미지별 총구 화염을 유지해요.
- 지방 파괴물은 `fatwall`, 웨이브마다 10초에 나타나는 보너스 소품은 `trapcage`·`traplock`을 사용해요. 12초 안에 자물쇠를 맞히면 250점과 코어 +2를 받으며 `item_glp1`·`item_gcgr`는 회복 보상 연출로 떠올라요. 기존 보스 회복은 즉시 적용해요.
- 후반 웨이브의 기존 스폰 간격 안에서 라면·담배·소주·나방·박쥐를 순환시키고 암세포 조각은 `cancerlet_0/1`로 표시해요. 기존 `fragment` 검증 API도 유지해요.

## 검증 결과와 제한

`node --experimental-vm-modules astra/tests/verify.mjs`를 통과했어요. 7맵의 3웨이브·3보스와 퀴즈 자동 플레이에 더해 이미지 알파 피격·프레임 전환·사망 정리·무기 12종·자물쇠 보상·경로 편집·오클루더·자동 품질을 검사했어요. 문제은행 공유, 기본 drug 제외, Fisher–Yates, `astra_` 접두사를 유지해요.

일반 적 두 마리가 있는 기본 장면의 메시·스프라이트 노드는 24개로 확인됐으며 기존 60fps 목표와 자동 품질 조절을 유지해요. 이 수치는 실측 FPS가 아니에요.

HTTP 서버 바인딩이 권한 오류로 거부됐고 소켓 없이 시도한 Chrome 실행도 `SIGABRT`로 종료돼 실제 GPU 화면과 FPS는 확인하지 못했어요. `ASTRA_PIPE_ASSETS=1 node astra/tests/browser.mjs`에 7맵 스크린샷과 첫 웨이브 자동 플레이 절차를 남겼어요.
