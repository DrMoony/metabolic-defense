# ASTRA · Metabolic Defense

학회 부스용 마우스·절대좌표 라이트건 디펜스 게임. `beta/`의 CKLM 컨셉과 밸런스 데이터를 참고하고, 화면 구조·전투 상태 관리·3D 모델·렌더링은 새로 작성했습니다. 변경 파일은 모두 `astra/`에 있습니다.

## 실행

저장소 루트에서:

```sh
python3 -m http.server 8765
```

`http://localhost:8765/astra/` 접속. npm 설치, 번들러, CDN, 외부 폰트가 필요하지 않습니다. WebGL2 지원 브라우저가 필요합니다. `file://`로 열면 모듈·문제은행 로딩이 제한되므로 HTTP 서버를 사용하세요.

시작 화면에서 한국어/English와 EASY/NORMAL/HARD를 선택하고 **방어 시작하기 → 방어선 진입**을 누릅니다. 진입 버튼은 전체화면도 요청합니다. 지원하지 않으면 창 모드에서 진행합니다.

- 화면을 조준하고 좌클릭. 누르고 있으면 현재 무기 속도로 연사합니다.
- EASY는 무제한 탄약. NORMAL/HARD는 탄약 소진 시 자동 재장전합니다. 화면의 **재장전** 버튼으로 미리 장전할 수도 있습니다.
- **무기 교체** 버튼 또는 우클릭으로 획득한 무기를 순환합니다.
- 퀴즈는 **보기 선택 → 정답 제출**의 두 단계입니다. 제한 시간은 18초. 시간이 끝나면 선택한 답을 제출하며, 선택하지 않았으면 오답입니다.
- 결과는 4초간 표시하고 전투로 복귀합니다. **계속하기** 버튼으로 먼저 복귀할 수 있습니다.
- 화면 위의 일시정지·재개·음향·전체화면 버튼을 사용합니다. 창 포커스를 잃거나 탭을 숨기면 전투와 퀴즈를 일시정지합니다.
- 결과 화면에서 다시 도전하면 언어·난이도 선택으로 돌아갑니다. 키보드는 필수가 아닙니다.

## 2차 3D 설계 · a4

참조의 버건디·금색 색감에 맞춰 실제 기하로 공간을 다시 구성했습니다. 배경 이미지나 참조 캐릭터의 평면 스프라이트를 사용하지 않습니다. Three.js r170을 `../vendor/three.module.js`에서 직접 가져오며 Blender 에셋·추가 로더·빌드 도구는 필요하지 않습니다.

- 붉은 혈관 길: 원근에 따라 넓어지는 306개 타일, 굽은 혈관 난간, 비대칭 회랑, 원경의 매달린 조직과 분지 혈관.
- 황금색 지방 조직: 2,100개의 조직을 하나의 InstancedMesh로 렌더링합니다. 타일과 조직에는 공유 절차적 미세 요철 텍스처를 적용했습니다.
- 간: 베지어 윤곽을 돌출한 둥근 몸체, 금장 테두리와 받침대, 에메랄드 보석, 발광 혈맥, clearcoat 광택. 섬유화 상태에 따른 변색을 유지합니다.
- 췌장: 다엽 조직, 혈관 지지대, 청색 발광 혈맥·회전 포신, 금장 받침대.
- 몬스터: 둥근 감자튀김 포장, 나선 캔디, 큰 눈과 반사 하이라이트, 볼·입·장갑·운동화. 고정 장식은 재질별로 병합하고 다리·보스 약점은 독립시킵니다.
- 광원: 반구광, 주광·분홍 역광·차가운 보조광, 장기 주변 점광원. 작은 절차적 반사 환경으로 금속과 곡면에 넓은 하이라이트를 줍니다.
- 깊이: 버건디 지수 안개, 49도 시야각, 실제 접근 이동과 미세한 크기 변화, 거리별 조명. 가까운 적만 동적 그림자를 만들고 모든 적은 거리에 따라 진해지는 접지 그림자를 가집니다.
- 새총: 굽은 나무 포크, 당겨진 밴드, 금속 장식·발광 보석. idle sway·피격 셰이크·사격 반동을 유지합니다.
- 발광: 장기 주변 작은 additive 스프라이트와 emissive. 기존 깊이 텍스처·전체 화면 블러/블룸·HDR 중간 렌더 타깃은 제거했습니다. 실제 거울 반사는 사용하지 않습니다.
- HUD: 따뜻한 반투명 패널을 화면 모서리에 작게 배치해 공간을 더 많이 보여줍니다. 16:9 레터박스와 마우스 조작은 유지합니다.

### 60fps 예산과 자동 품질

`main.js`는 시뮬레이션 시간과 분리된 실제 rAF 간격을 1초 단위로 측정합니다. 정수 반올림한 FPS가 2개 구간 연속 60 미만이면 품질을 한 단계 내립니다. 숨긴 탭·일시정지·수동 스텝·250ms 초과 중단은 집계에서 제외합니다. 안정적인 60fps가 20개 구간 지속되고 마지막 변경 후 30초가 지나야 한 단계 복구합니다.

| 품질 | 그림자 맵 | 부유 입자 | 격파 입자 상한 | DPR 상한 |
| --- | --- | --- | --- | --- |
| 0 | 1024 | 72 | 128 | 1.5 |
| 1 | 512 | 40 | 64 | 1.25 |
| 2 | 256 | 18 | 32 | 1.0 |
| 3 | 끔, 접지 그림자 유지 | 8 | 16 | 0.8 |

격파 입자는 단일 InstancedMesh를 사용합니다. 정적 장식과 캐릭터 장식은 공유 재질별로 병합합니다. 검증 장면은 적 2개 포함 120개의 그리기 오브젝트를 가집니다. 이는 GPU 드로우콜 측정값이 아니며 그림자 패스와 실제 적 수에 따라 호출 수가 달라집니다. 실제 호출 수·삼각형 수·FPS·95백분위 프레임 시간은 `ASTRA.performance`에서 확인할 수 있습니다. 화면 아래에도 FPS를 표시합니다. 모든 장치에서 60fps가 보장되는 것은 아니며 실제 GPU 성능 검증은 아래 제한을 확인하세요.

**세 보스를 모두 처치해야 승리**합니다. 제한 시간이 지났다고 살아 있는 보스를 삭제하지 않습니다. 보스를 놓친 웨이브는 남은 적 정리 후 실패로 끝납니다. 암세포 분열 조각도 정리해야 다음 웨이브로 이동합니다.

beta의 배치 편집기·지방 덫 구출·약물 드롭·일부 일반 적은 이 버전에 포함하지 않았습니다. 보스 보상은 이름 없는 정화 지원과 장기 회복, 일반 적 보상은 소량의 즉시 회복으로 구성했습니다. 무기 모델은 절차적으로 조립하고, 화면 레이캐스트와 공간 투사체를 별도로 관리합니다.

## 문제은행 규칙

새 문제나 비상 대체 문제를 만들지 않습니다. 아래 파일을 그대로 fetch합니다.

- `../assets/quiz_aasld_ko.json`, `../assets/quiz_aasld_en.json`
- `../assets/quiz_obesity_ko.json`, `../assets/quiz_obesity_en.json`

기본은 MASLD 70 : Clinical Obesity 30, `drug: true` 문항은 제외합니다. 시작 화면의 **운영자 설정**에서만 약물 문항을 포함할 수 있습니다. 어드민은 부스 운영 편의용 패널이며 인증 기능은 아닙니다.

설정 가능한 비율은 100:0, 70:30, 50:50, 30:70, 0:100입니다. 10문 단위 세트 일정을 Fisher–Yates로 섞어 정확한 비율을 유지합니다. 한 판은 보통 7문이므로 개별 판의 비율에는 표본 차이가 있습니다. 지정 세트 안에서 최근 출제를 피한 후 선택 난이도를 우선합니다. 풀이 소진되면 아직 이번 판에서 쓰지 않은 문제, 마지막으로 가장 오래전에 출제한 문제 순서로 완화합니다. 질문 선택과 보기 순서 모두 Fisher–Yates를 사용합니다.

최근 24문항을 `세트:원본배열인덱스`로 저장하므로 언어를 바꿔도 같은 문항의 반복을 피합니다. 원본 문제은행의 순서를 재배열한 경우에는 기존 이력이 다른 문항을 가리킬 수 있습니다.

localStorage는 전부 `astra_` 프리픽스입니다: `astra_mix`, `astra_drug`, `astra_recent`, `astra_muted`, `astra_best`. 저장 접근이 차단되어도 플레이는 가능합니다. 이때 이력과 설정의 다음 페이지 방문까지 보존은 보장하지 않습니다. 양쪽 문제은행이 모두 정상 로드될 때까지 시작을 막으며, 로딩 실패 시 재시도 버튼을 표시합니다. 언어 전환 시 오래된 로딩 응답이 최신 선택을 덮지 않도록 요청 세대를 확인합니다.

## 파일과 디버그

- `index.html`, `style.css`: 16:9 스테이지, 이중 언어 UI, 마우스 전용 조작.
- `main.js`: 전투·웨이브·퀴즈 상태, 입력, HUD, 합성 오디오.
- `world.js`: 캐릭터, 조명, 접지·동적 그림자, 레이캐스트, 인스턴스 파티클.
- `art.js`: 혈관 지형, 금장 장기, 절차적 반사·요철, 정적 메시 병합.
- `quiz.js`: 공유 문제은행과 설정·최근 이력.
- `tests/verify.mjs`: 외부 패키지 없는 로직·자동 품질 검증.
- `tests/browser.mjs`: Chrome DevTools pipe를 사용하는 실제 브라우저 한 웨이브 검증과 스크린샷 수집.

진입 스크립트는 `main.js?v=a4`입니다. 배포 수정 시 이 버전을 올리세요. 모듈별 캐시도 함께 갱신하도록 import URL에 같은 버전을 사용합니다.

브라우저 콘솔:

```js
ASTRA.setManual(true);       // requestAnimationFrame의 자동 진행 중지
ASTRA.start();               // 문제은행 로드 완료 후 호출
ASTRA.step(10);              // 1/60초 하위 스텝으로 10초 진행
ASTRA.state;                // 상태, 체력, 점수, 웨이브, 퀴즈 등
const enemy = ASTRA.spawn('burger', { lane: 0, progress: 0.6 });
ASTRA.step(1 / 60);
const p = ASTRA.project(enemy);
ASTRA.shot(p.x, p.y);        // 실제 화면 좌표로 사격
ASTRA.setManual(false);      // 자동 진행 복원
```

추가 핸들: `enemies`, `world`, `bank`, `WEAPONS`, `TYPES`, `WAVES`, `reload`, `swap`, `pause`, `openQuiz`, `answerQuiz`, `continueQuiz`.
