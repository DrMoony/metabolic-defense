# ASTRA · Metabolic Defense

7개 맵을 `../assets/maps/map_<key>.jpg` 플레이트 위에서 플레이할 수 있어요. 그림 속 길을 화면좌표로 추적하고 y=0 평면으로 역투영해 3D 적이 따라가는 스플라인을 만들었어요. 장기·파괴물·다리·이펙트는 3D로 그리며 빌드 도구 없이 `../vendor/three.module.js`를 직접 가져와요.

## 실행과 조작

저장소 루트에서 `python3 -m http.server 8765`를 실행한 뒤 `http://localhost:8765/astra/`를 열어요. 모듈 캐시 버전은 `a6`예요.

- 맵·언어·난이도를 고르고 방어 시작하기 → 방어선 진입으로 진행해요.
- 마우스로 조준하고 좌클릭을 누르면 연사하며 재장전·무기 교체·일시정지·퀴즈는 화면 버튼으로 조작해요.
- **R**은 실제 경로선 표시, **D**는 경로 편집기 열기·닫기예요. 일반 플레이에는 키보드가 필요 없어요.

좌표는 원본 1672×941 그림을 기준으로 잡아 0–1 범위로 저장해요. 아래 총점은 각 경로 배열과 공통 구간 배열의 길이를 더한 값으로, 배열 경계에서 반복되는 합류점도 포함해요.

| --- | --- | --- | --- | --- | --- | --- |
| coronary | Y 합류 | left 10, right 10 | 5 | 25 | 중앙 약간 왼쪽 중거리 광장 | 우측 전경 원형 단 |
| omentum | 갈림 없는 S자 | s-road 22 | 0 | 22 | 좌측 중거리 언덕 위 단 | 우측 전경 단 |

관상동맥에는 합류 전 플라크 2개, 내장지방에는 지방 둔덕 2개, 경동맥에는 분기부 플라크 1개가 있어요. 실제 메시를 쏘면 체력이 줄고 파괴 보상 250점과 코어 +2를 받아요. 위의 징검다리 7개와 시누소이드·사구체·췌장섬의 다리·섬유화 띠도 그림의 해당 위치에 겹쳐 있어요. 파괴하면 3D 오브젝트가 사라지며 배경 그림 자체는 유지돼요.

## 경로 편집기

**D**로 열면 전투·퀴즈·발사 대기가 멈추고 경로점과 번호가 나타나요. 패널에 가려진 점은 **H / 패널 숨기기**로 패널을 접은 뒤 수정할 수 있어요.

1. 점을 드래그하거나 점을 선택한 뒤 새 위치를 클릭해 옮겨요.
2. 경로 선택 메뉴에서 편집할 경로를 고를 수 있어요. **Shift+클릭**은 선택한 점 다음에 새 점을 넣으며 선택한 점이 없으면 도착점 앞에 추가해요.
3. **Alt+클릭 / Delete / Backspace**로 중간 점을 지워요. 시작점과 도착점은 드래그로 옮기고 경로마다 최소 2점을 유지해요.
4. **저장 / Ctrl·⌘+S**로 `astra_routes_<map>`에 저장하고 **JSON 내보내기**로 파일을 내려받아요. JSON 펼치기에서 내용을 복사하거나 붙여넣고 적용할 수도 있어요.
5. **되돌리기 / Ctrl·⌘+Z**, **저장본 불러오기**, **기본 경로 미리보기**로 수정 내용을 되돌릴 수 있어요. 기본 경로도 저장을 눌러야 저장본을 대체해요.
6. **D / Esc / 닫기**로 전투에 돌아가요. 닫기만 하면 수정 내용은 현재 판에 적용되고 다음 판이나 새로고침에는 저장본을 사용해요.

Y·역Y 합류점과 시누소이드 도착점은 서로 연결돼 함께 이동해요. 평행 경로의 도착점은 분리하며 범위를 벗어난 값·잘못된 맵·끊어진 합류·중복 인접점은 적용하지 않아요. 읽을 수 없는 저장본은 기본 경로로 폴백하고 저장 공간 차단은 편집기 안에 표시해요. 이때 JSON 내보내기로 보관할 수 있어요.

```json
{
  "version": 1,
  "map": "omentum",
  "space": "normalized-screen",
  "topology": "S",
  "routes": [{ "id": "s-road", "points": [[0.86, 0.12], [0.48, 0.98]] }],
  "trunk": []
}
```

위 JSON은 형식 설명을 위한 2점 예시예요. 실제 경로는 편집기에서 내보낸 값을 사용해요.

## 렌더링과 파일

- `maps/plates.js`: 7개 플레이트, 경로점, 맵별 카메라 높이/FOV, 장기 앵커, 지형지물과 가림 폴리곤.
- `maps/index.js`: 기존 맵 메타데이터와 플레이트 설정 결합. `legacy`에 3차 원본 데이터를 보존해요.
- `plate.js`: 화면좌표 역투영, 저장본 검증, 플레이트 지형과 깊이 전용 오클루더.
- `routes.js`: 호 길이 기반 centripetal Catmull–Rom 보간. 독립 경로와 선택적 공통 구간을 지원해요.
- `route-editor.js`: 점 편집·되돌리기·저장·JSON 입출력.
- `terrain.js`: 기존 3차 3D 지형. 기존 3맵에서 `plate` 필드를 제거하면 해당 원본 지형을 사용해요.
- `world.js`: alpha 렌더러, 플레이트 카메라 고정, 장기 배치, 몬스터와 레이캐스트.
- `main.js`: 맵 선택·전투·퀴즈·HUD·자동 품질과 검증 훅.

플레이트와 캔버스는 같은 16:9 스테이지를 꽉 채워요. 플레이트 모드에서는 카메라 드리프트·진입 비행·화면 흔들림을 멈춰 그림과 투영이 일치하도록 했어요. 몬스터는 길을 따라 움직이면서 얼굴을 카메라 쪽으로 향해요. 코어는 가까운 도착점에 있고 췌장섬의 두 도착점은 공통 체력을 사용해요.

언덕·혈관 벽·단의 실루엣은 `colorWrite:false`, `depthWrite:true` 메시로 깊이만 기록해 뒤쪽 몬스터를 가려요. 사격도 같은 메시를 검사해 가려진 적을 직접 맞힐 수 없고 앞쪽 적은 정상적으로 맞아요. 품질이 내려가도 가림 메시·다리·파괴물은 유지해요.

## 성능과 공통 규칙

60fps를 목표로 기존 자동 품질 조절을 유지해요. 실제 rAF 간격에서 60fps 미만이 2구간 이어지면 장식 밀도·그림자·입자·DPR을 단계적으로 낮추고 안정된 프레임이 이어지면 복구해요. 편집기·일시정지·수동 스텝·숨긴 탭은 성능 집계에서 제외해요. 플레이트 모드의 장식 밀도는 100/75/50/25%이며 파괴물은 인스턴싱하고 격파 입자는 최대 128개로 제한해요.

일반 적·3보스·12단 무기·간 정화·췌장 자동 사격을 공유하며 췌장은 플레이트 경로 진행률 30% 이후의 당류 적을 요격해요. 문제은행 네 파일은 그대로 읽고 기본 약물 문항 제외, Fisher–Yates 섞기, 최근 24문항 회피, `astra_` 저장 접두사를 유지해요.

```js
ASTRA.setManual(true);
ASTRA.selectMap('sinusoid'); // 타이틀·브리핑·결과에서 선택
ASTRA.start();
const enemy = ASTRA.spawn('fries', { routeId: 'portal-left', progress: 0.6 });
ASTRA.step(1 / 60);
const point = ASTRA.project(enemy);
ASTRA.shot(point.x, point.y);
ASTRA.editor.toggle(true);
ASTRA.world.terrain.document; // 현재 화면좌표 경로
ASTRA.world.terrain.routes.items; // 역투영된 실제 스플라인
ASTRA.editor.toggle(false);
ASTRA.setManual(false);
```

## 검증

```sh
node --experimental-vm-modules astra/tests/verify.mjs
```

실제 Three.js 기하·레이캐스트로 7맵의 3웨이브·3보스 승리, 스폰·도착점·장기 앵커 투영, 지상·비행 적, 분열 경로, 파괴물 피격·보상, 오클루더 앞뒤의 피격 차이, 경로 편집·저장·복원·잘못된 저장본, 자동 품질과 기존 3D 폴백을 검사해요. 검증기의 병렬 모듈 로드 캐시도 수정해 게임 코드와 월드가 같은 맵 인스턴스를 사용하도록 했어요.

DOM과 WebGLRenderer를 대체하는 테스트이므로 실제 화면·GPU 셰이더·전체화면·실측 FPS는 별도 검증이 필요해요. 이번 환경에서는 HTTP 서버 바인딩이 제한됐고 기존 localhost 서버의 브라우저 접근도 자동 보안 검토에서 권한 거절로 차단돼 시각 검증을 수행하지 못했어요. `tests/browser.mjs`는 브라우저 접근이 가능한 환경에서 실행할 수 있어요.

`astra/` 밖 파일은 수정하지 않았고 커밋하지 않았어요.
