# ASTRA · Metabolic Defense

빌드 도구 없이 실행하는 Three.js 몸속 디펜스 게임이에요. `coronary` → `omentum` → `sinusoid` 순으로 세 맵을 구현했고, 공통 몬스터·12단 무기·퀴즈를 각 맵에서 플레이할 수 있어요. 나머지 네 맵은 데이터 뼈대만 있으며 타이틀에 준비 중으로 표시해요.

## 실행과 조작

저장소 루트에서 `python3 -m http.server 8765`를 실행하고 `http://localhost:8765/astra/`를 열어요. Three.js는 `../vendor/three.module.js`를 직접 가져오며 CDN·npm·외부 폰트를 사용하지 않아요. 진입점과 모듈 캐시 버전은 `a5`예요.

1. 타이틀에서 맵과 언어·난이도를 고른 뒤 **방어 시작하기**를 눌러요.
2. 맵별 브리핑에서 경로와 방어 대상을 확인하고 **방어선 진입**을 눌러요. **맵 선택**으로 돌아갈 수도 있어요.
3. 마우스로 조준하고 좌클릭을 누르고 있으면 연사해요. 탄약을 다 쓰면 자동으로 장전하며 EASY에서는 탄약이 무제한이에요.
4. 재장전·무기 교체·일시정지·퀴즈 선택과 제출을 모두 화면 버튼으로 조작해요. 우클릭도 무기를 교체해요.
5. **경로선 보기** 버튼이나 선택적 디버그 키 **R**로 실제 스플라인을 확인해요. 키보드는 필수가 아니에요.
6. 세 보스를 모두 처치하고 남은 적을 정리하면 결과 화면으로 이어져요. 다시 도전하면 맵 선택으로 돌아가요.

## 맵 구성

| 맵 | 경로 | 코어 | 지형지물 |
| --- | --- | --- | --- |
| coronary / 관상동맥 | 좌우 2경로 → 공통 길 | 심장 | Y자 혈관 분지, 파괴 가능한 플라크 협착 2곳, 박동하는 조직 벽 |
| omentum / 내장지방·장간막 | 지방세포 사이 3골목 → 공통 길 | 간 문맥 | 황금 지방 언덕, 파괴 가능한 지방 둔덕 2곳, 염증 대식세포 군집, 장간막 혈관, 문맥 게이트 |
| sinusoid / 간 소엽·시누소이드 | 문맥 쪽 3방사형 유입로 → 공통 길 | 중심정맥 | 간세포판, 쿠퍼세포, 웨이브에 따라 굵어지는 섬유화 띠, 중심정맥 게이트 |
| carotid / 경동맥 | 데이터 뼈대 | 뇌혈관 | 경동맥 팽대부 플라크·상행 경로·협착 게이트 계획 |
| stomach / 위 | 데이터 뼈대 | 유문 | 위벽 주름·위산 웅덩이·유문 게이트 계획 |
| glomerulus / 사구체·요관 | 데이터 뼈대 | 사구체 | 모세혈관 미로·세뇨관 굽이·요관 터널 계획 |
| islet / 랑게르한스섬 | 데이터 뼈대 | 베타세포 섬 | 섬 사이 수로·인슐린 분비관·지친 베타세포 계획 |

지형은 해부학의 특징을 게임 공간으로 각색했으며 정확한 해부도나 혈류 시뮬레이션은 아니에요. 협착 둔덕은 길 가장자리를 실제로 차지하고 사격을 가로막으며, 파괴하면 공간을 열고 250점과 코어 +2를 받아요. 적의 중앙 이동선은 유지하고 길찾기 재계산은 하지 않아요. 대식세포·쿠퍼세포는 공격 대상이 아닌 장식이에요.

분지부 플라크 표현은 낮거나 교란된 벽 전단응력과 플라크 분포의 관련성을 참고했어요. [혈관 분지의 혈류·기하와 죽상경화](https://pubmed.ncbi.nlm.nih.gov/26740210/). 간 소엽의 섬유화 표현은 지방간의 염증·섬유화에 관한 [NIDDK 설명](https://www.niddk.nih.gov/news/archive/2024/making-new-connections-address-silent-epidemic-nonalcoholic-fatty-liver-disease)을 참고했으며, 웨이브별 진행과 사격 회복은 게임 규칙이에요.

## 경로와 렌더링

`maps/*.js`에서 맵별 팔레트·안개·스폰 경로·공통 길·지형지물·코어 이름·브리핑을 정의해요. 각 경로는 centripetal Catmull–Rom 스플라인이며 분지 구간 뒤에 동일한 공통 길을 연결해 코어 앞에서 정확히 합류해요. 호 길이 기준으로 보간하고 기존 웨이브 밸런스를 유지하도록 경로별 총 이동 시간을 맞췄어요.

적 위치와 길 타일·난간·발광 가장자리·디버그 선이 같은 경로를 사용해요. 지상 적은 길 높이를 따르고 비행 적은 같은 경로 위에 떠 있으며, 둘 다 경로의 접선 방향으로 회전해요. 암세포 보스의 분열 조각도 부모의 경로와 진행률을 이어받아요.

길 주변의 조직은 경로와의 거리를 확인해 배치하고 반복 조직·길 타일·둔덕·세포를 인스턴싱해요. 정적인 장식은 재질별로 병합하고 맵 교체 시 이전 지형의 기하·인스턴스·전용 재질을 해제해요. sinusoid의 섬유화 띠는 웨이브가 바뀔 때 실제 튜브 반지름이 0.11 → 0.209 → 0.308로 커져요.

타이틀은 큰 세리프 ASTRA 타이포와 움직이는 3D 맵을 배경으로 사용하고 맵 선택 시 카메라가 새 공간으로 들어가요. 브리핑·결과에는 맵별 제목과 코어 이름을 표시하며, 카메라 드리프트·지수 안개·additive 광선·발광 스프라이트로 깊이를 더해요. 전체 화면 블러·블룸이나 별도 HDR 후처리 타깃은 사용하지 않아요.

## 60fps 예산과 자동 품질

실제 rAF 간격을 1초 단위로 측정하고 60fps 미만이 두 구간 이어지면 품질을 낮춰요. 첫 단계에서는 지형 장식 밀도만 줄이고 길과 파괴 가능한 지형지물은 유지해요. 안정적인 60fps가 20구간 이어지고 마지막 변경 후 30초가 지나면 한 단계 복구해요. 숨긴 탭·일시정지·수동 스텝·250ms 초과 중단은 집계에서 제외해요.

| 품질 | 지형 장식 밀도 | 그림자 | 부유 입자 | DPR 상한 |
| --- | --- | --- | --- | --- |
| 0 | 100% | 1024 | 72 | 1.5 |
| 1 | 68% | 1024 | 72 | 1.5 |
| 2 | 42% | 512 | 40 | 1.0 |
| 3 | 24% | 끔, 접지 그림자 유지 | 8 | 0.8 |

격파 입자는 단일 InstancedMesh를 사용하고 품질별 상한은 128 / 128 / 64 / 16개예요. `ASTRA.performance`에서 FPS·프레임 시간·p95·실제 드로우콜·삼각형 수를 확인할 수 있어요. 60fps는 목표 예산이며 이번 환경에서 실제 GPU 성능을 측정하지 못했어요.

## 공통 게임 규칙과 문제은행

일반 적·보스·12단 무기·간 정화 파동·췌장 자동 사격은 맵 전체에서 공유해요. 웨이브는 40 / 60 / 70초이며 각 웨이브의 보스를 놓치면 승리할 수 없어요. 퀴즈는 선택 후 제출하는 두 단계로 진행하고 정답이면 무기 승급과 장기 회복을 받아요. 췌장부전은 한 판 동안 유지해요.

기존 문제은행 네 파일을 그대로 읽고 새 문항을 만들지 않아요.

- `../assets/quiz_aasld_ko.json`, `../assets/quiz_aasld_en.json`
- `../assets/quiz_obesity_ko.json`, `../assets/quiz_obesity_en.json`

기본 MASLD : Clinical Obesity 비율은 70 : 30이고 `drug: true`는 기본 제외예요. 운영자 설정에서만 약물 문항을 포함할 수 있으며 세트 일정·문제·보기는 Fisher–Yates로 섞어요. 최근 24문항 이력과 설정은 `astra_` 접두사가 붙은 localStorage 키로 저장하고 저장이 차단되면 현재 페이지 안에서 동작해요. 두 문제은행의 로드가 끝날 때까지 시작 버튼을 잠가요.

## 파일과 디버그

- `maps/*.js`: 완성한 3맵과 준비 중인 4맵의 데이터.
- `routes.js`: 거리 보간과 공통 길 합류.
- `terrain.js`: 길·지형지물·게이트·코어·밀도 조절·해제.
- `art.js`: 장기 모델·표면·정적 메시 병합.
- `world.js`: 조명·몬스터·레이캐스트·카메라·맵 교체.
- `main.js`: 전투·퀴즈·맵 선택·HUD·지형지물 레이블.
- `quiz.js`: 공유 문제은행과 이력. 이번 작업에서는 변경하지 않았어요.
- `tests/verify.mjs`: 실제 Three.js 기하·레이캐스트와 게임 로직을 사용하는 검증.
- `tests/browser.mjs`: 권한이 허용되는 환경에서 별도로 실행할 실제 브라우저 검증.

```js
ASTRA.setManual(true);
ASTRA.selectMap('sinusoid'); // 타이틀·브리핑·결과에서 선택
ASTRA.start();
const enemy = ASTRA.spawn('fries', { routeId: 'portal-left', progress: 0.6 });
ASTRA.step(1 / 60);
const point = ASTRA.project(enemy);
ASTRA.shot(point.x, point.y);
ASTRA.world.toggleRoutes();
ASTRA.world.terrain.landmarks;
ASTRA.world.terrain.routes.items;
ASTRA.setManual(false);
```

기존 `lane` 디버그 옵션도 유지하며 현재 맵의 경로 인덱스로 변환해요. 실제 적은 `routeId`와 `progress`로 이동해요.

## 검증 결과와 남은 제한

```sh
node --experimental-vm-modules astra/tests/verify.mjs
```

2026-09-06 실행에서 아래 항목을 통과했어요.

- 공유 KO/EN 문제은행, 기본 약물 제외와 운영자 포함, 혼합 비율, 최근 이력, 저장 키 격리.
- 실제 레이캐스트 일반 사격·시럽통 약점, 장전·승급·교체, EASY 탄약, 일시정지·퀴즈 시간 초과, 보스 누락 패배·췌장부전.
- 타이틀 3맵 선택·4맵 잠금, 맵별 브리핑·코어, 이전 지형 제거.
- 모든 경로의 스폰·종점·공통 길 합류, 지상·비행 위치와 회전, 부모 경로 위 보스 분열.
- 실제 InstancedMesh 둔덕 사격·파괴·보상 중복 방지·재시작 복원.
- 장식 밀도 우선 감소, 길과 사격 대상 유지, 품질 복구, 섬유화 반지름 증가.
- coronary·omentum·sinusoid 각각 NORMAL에서 일반 레이캐스트 사격으로 3웨이브·3보스 승리.

검증기는 DOM과 WebGLRenderer를 대체하므로 GPU 셰이더·실제 화면 배치·마우스 장치·전체화면·실측 FPS까지 검증한 것은 아니에요. 로컬 HTTP 서버 소켓 바인딩은 `Operation not permitted`로 차단됐고, 브라우저 localhost 접근도 자동 승인 검토에서 권한 거절로 중단됐어요. 브라우저를 통한 우회 실행은 하지 않았으며 실제 시각 검증은 남아 있어요.

`astra/` 밖의 파일을 수정하지 않았고 커밋하지 않았어요.
