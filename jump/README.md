# 메타볼릭 점프 (Metabolic Jump)

대사건강 학회 부스용 **사이드스크롤 플랫포머**. 「메타볼릭 디펜스」(라이트건 슈터)와 같은 세계관·같은 문제은행을 쓰는 자매 게임이에요.

- 플레이: `/jump/` (로컬은 `python3 -m http.server 8765` 후 http://localhost:8765/jump/)
- 조작: **←→ / A·D** 이동, **스페이스·↑·W** 점프(길게 누르면 더 높이), 모바일은 화면 버튼
- 라이트건이 아니라 **키보드·터치** 기반이에요. 부스에 게임패드를 붙이려면 Gamepad API를 얹으면 돼요.

## 규칙
| 요소 | 내용 |
|---|---|
| 🍔 정크푸드 | 머리를 밟으면 처치, 옆으로 닿으면 피해 |
| ❓ 퀴즈 블록 | 아래에서 치면 문제 출제 → 정답이면 브로콜리 3개 + 파워업 |
| 🥦 브로콜리 | 점수. 파워업으로 먹으면 커져서 한 대 버팀 |
| 💧 수분 | 6.5초 무적 |
| 👟 운동화 | 11초 동안 이동·점프 상승 |
| 🚩 깃발 | 스테이지 클리어 |

## 스테이지
1. **1-1 위장 들판** — 버거 굼바, 기본기
2. **1-2 간 동굴** — 도넛(비행)·지방 덩어리(2회 밟기), 구덩이 증가
3. **1-3 혈관 성채** — 소다 점퍼 + **보스 ☠️ 플라크 왕**(3회 밟기, 체력 핍 표시)

## 문제은행
`../assets/quiz_aasld_*.json`(MASLD/MASH 46문) + `../assets/quiz_obesity_*.json`(Clinical Obesity 38문)을 그대로 공유해요.
**특정 약물 문항(`drug: true`)은 기본 숨김** — 공정경쟁규약 대응. 문항 편집은 루트의 `quiz-admin.html`에서 하면 두 게임에 동시에 반영돼요.

- 세트 비율: `localStorage.mj_quizmix` (기본 70 = MASLD 70 : Obesity 30)
- 약물 문항 포함: `localStorage.mj_quizdrug = '1'`
- 최근 출제 회피: `localStorage.mj_recentq` (최근 20문)

## 밸런스 근거 (헤드리스 실측)
- 점프 최대 수평거리 ≈ **5칸** → 모든 구덩이를 **4칸 이하**로 제한. 전 스테이지 구덩이 **17/17 통과** 확인
- 적을 뺀 지형 주파: 1-1 95% · 1-2 96% · 1-3 91%(보스 구간까지)
- 보스: 3회 밟기로 격파, 각 타격 후 1.1초 무적 + 이동속도 상승

## 디버그
브라우저 콘솔에서 `MJ` 로 접근해요. `MJ.buildLevel(MJ.LEVELS[2])`, `MJ.step(1/60)`, `MJ.render()`,
`MJ.player()`, `MJ.enemies()`, `MJ.boss()`, `MJ.touchState`(입력 강제) 등.
`main.js?v=jN` 캐시버스터는 **코드 수정할 때마다 올려야** 해요.
